# ECO3121 Problem Set 2

Collaborative coursework project. Complete draft: Questions 1--9.

- `code/q1.py`, `code/q2.py`, `code/q4.py`, `code/q5.py`, `code/q6.py`, and `code/q7.py`: reproducible regressions and numerical checks (q1.py also generates Q3).
- `results/`: generated estimates and LaTeX table.
- `main.tex`: main LaTeX document; compile this file in Overleaf.
- `sections/`: answers and interpretations for all nine questions.
- `STUDY_NOTES.md`: explanations of the econometric ideas.
- `data/`: supplied CSV and Stata data.
- `WORKFLOW.md`: installation, build, and synchronization instructions.

fit statistics. Q4 includes the approved explanation. Q5 reports the simple-regression slope.
Q6 includes the numerical comparison and approved commentary.
Q7 includes the numerical verification and interpretation. Q8 and Q9 explain
omitted-variable bias and homoskedasticity. Review the answers and replace
the name/student ID placeholder before submitting. Submit the Python code
and requested output along with the assignment, as instructed.
