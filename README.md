# ECO3121 Problem Set 2

Collaborative coursework project. Current scope: Questions 1--3.

- `code/q1.py` and `code/q2.py`: reproducible regressions and numerical checks (q1.py also generates Q3).
- `results/`: generated estimates and LaTeX table.
- `main.tex`: main LaTeX document; compile this file in Overleaf.
- `sections/q1.tex` and `sections/q2.tex`: student interpretations.
- `data/`: supplied CSV and Stata data.
- `WORKFLOW.md`: installation, build, and synchronization instructions.

Q1 and Q2 include student-approved interpretations. Q3 reports the requested
fit statistics. Questions 4--9 have not been implemented.
