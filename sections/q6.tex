\section*{Question 6}
Both regressions include an intercept and use the same 200 observations.
Following the question's notation, the explained sum of squares is
\[
\mathrm{SSE}=\sum_{i=1}^{200}
\left(\widehat{\mathrm{wage}}_i-\overline{\mathrm{wage}}\right)^2.
\]
\input{results/q6_table}

\paragraph{Comparison.}
Using the same 200 observations, adding ability increases $R^2$ from 0.961
to 0.982 and the explained sum of squares from 37099.684 to 37929.604.
Thus, the model including ability fits the observed wages better. Since
these are nested OLS models, adding a regressor cannot decrease either
measure of fit.
