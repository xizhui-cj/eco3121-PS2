ECO3121 PS2 - Python code

Requires Python 3.12. Install dependencies and run:
    python -m pip install -r requirements.txt
    python PS2_code.py

Keep data/PS2_data.csv next to the script in the supplied folder structure.
The script runs all computational questions (Q1-Q7) and saves outputs in
code_output/. Q8-Q9 are conceptual questions answered in the report.
All regressions include an intercept and use usual OLS standard errors.
Calculations use full precision; printed results use three decimal places.
